# ポートフォリオサイト

個人制作のポートフォリオサイトです。作品紹介、ビジュアル、ダウンロード用の資料をまとめています。

## サイト内容
- トップページでプロフィールと制作概要を紹介
- 作品ごとの詳細ページ（説明、スクリーンショット、動画、ダウンロードリンク）
- 作品ごとの見せ方を統一しつつ、演出や導線を調整

## 技術構成
- Next.js (App Router)
- TypeScript
- CSS

## ディレクトリ構成
- `app/`: ページとコンポーネント
- `public/assets/`: 画像・動画・配布データ

## セットアップ
```bash
npm install
npm run dev
```

## デプロイ
Vercel でのデプロイを想定しています。

## メモ
- 配布用の大容量ファイルは Git LFS で管理しています。
